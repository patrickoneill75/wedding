Import the planning spreadsheet

Upload Wedding_Data.xlsx. Each part you tick replaces what's here now. Guests come from the Guest List tab, the budget from the Data tab, and weights and drink assumptions from Constants. Round 2 Invites and Decor are skipped.

Users

Who can sign in to the control panel with Google. An admin sees everything. A user sees only the pages ticked for them, like a coordinator with Run of show, Seating and Reports. Page access keeps things tidy; it isn't a vault, so only add people you trust with what those pages show.
